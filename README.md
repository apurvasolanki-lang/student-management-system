# Student Information Management System

A web-based application to manage student information using a three-tier cloud architecture.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Version Control:** Git and GitHub
- **Cloud Deployment:** Render

## Features
- Add student records
- View student information
- Update student details
- Delete student records
- Cloud database integration

## Run Locally
1. Clone this repository.
2. Install dependencies:
   `npm install`
3. Create a `.env` file and configure `MONGODB_URI`.
4. Start the server:
   `node server.js`
5. Open `http://localhost:5000` in your browser.

## Security
Keep your `.env` file and database credentials private. Never commit secrets to GitHub.
